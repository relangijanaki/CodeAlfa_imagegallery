Features

Responsive grid-based image gallery

Filter images by category (Nature, City, Animals)

Interactive lightbox for image preview

Previous and Next navigation inside lightbox

Smooth hover animations and transitions

Mobile-friendly responsive design

Clean and modern UI


Technologies Used

HTML5

CSS3

JavaScript (Vanilla JS)

Functionalities

Users can filter images dynamically using category buttons.

Clicking on an image opens it in a fullscreen lightbox.

Users can navigate through images using Prev and Next buttons.

Hover effects display image overlays with descriptions.

Responsive layout adapts to different screen sizes.
